🎬 Netflix Trends Analysis — Data Exploration & Insights

A data analysis project exploring viewing patterns, title popularity, and global content trends on Netflix using Python, Pandas, Matplotlib, and Seaborn.

📌 Overview

This project analyzes a Netflix dataset to uncover:

Which genres are most common

How content production has changed over time

Trends in movies vs. TV shows

Country-wise content distribution

Ratings, duration patterns, and more

The goal is to visualize and understand patterns that influence Netflix’s content strategy.

📂 Dataset

The dataset used in the notebook includes information such as:

Title

Genre

Release year

Added to Netflix date

Country

Rating

Duration

Description

🧠 Key Skills Used

Python

Data Cleaning (Pandas)

Data Visualization (Matplotlib, Seaborn)

Exploratory Data Analysis (EDA)

Handling missing values

Feature extraction & grouping

📊 Insights Extracted

✔ Growth in total Netflix releases over time
✔ Comparison of Movies vs. TV Shows
✔ Most frequent genres
✔ Countries producing the most content
✔ Analysis of rating categories
✔ Duration distribution for movies and shows
